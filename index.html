Health Dashboard

Personal Health Tracking App

This is a simple tool to track your blood pressure and heart rate over time. Enter your daily readings and view charts to monitor trends. You can install it as an app on your device!

Privacy & Security

  • • All data stays on your device - nothing is sent to servers
  • • Your health information is stored locally, offline
  • • Export your data anytime as JSON files
  • • No account required, no tracking, no data collection

JSON Import/Export Format

Example:
{
  "manifest": {
    "format": "health-dashboard-export",
    "version": "1.0.0",
    "exportedAt": "2024-01-15T10:00:00.000Z",
    "totalEntries": 1,
    "checksum": "sha256-abc123..."
  },
  "data": [
    {
      "id": "uuid-here",
      "date": "2024-01-15T09:30:00.000Z",
      "systolic": 120,
      "diastolic": 80,
      "heartRate": 75
    }
  ]
}
Export includes:
  • • manifest: Metadata with format version and SHA-256 checksum for data integrity
  • • data: Array of all health entries with unique IDs
Import requirements:
  • • Required fields: date, systolic, diastolic, heartRate
  • • Optional fields: id (auto-generated if missing), manifest (shows warning if missing)
  • • Date format: ISO 8601 or any parseable date string
  • • Valid ranges: Systolic 60-250, Diastolic 40-150, Heart Rate 30-220
Supported import formats:
  • • Full format with manifest and data (recommended)
  • • Simple array of entries: [{date, systolic, diastolic, heartRate}, ...]
  • • Object with entries property: {entries: [...]}
