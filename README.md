# Personal Health Dashboard

A modern, privacy-focused personal health tracking application built with TypeScript and deployed as a Progressive Web App (PWA).

## 🌟 Features

- **Blood Pressure & Heart Rate Tracking** - Log and monitor your daily readings
- **Interactive Charts** - Visualize trends over time with Chart.js
- **Time Filtering** - View data by week, month, 3 months, 6 months, year, or all time
- **Data Export/Import** - CSV and JSON export for sharing with healthcare providers
- **Privacy First** - All data stored locally on your device using IndexedDB
- **Progressive Web App** - Install on your phone or desktop, works offline
- **Responsive Design** - Works seamlessly on mobile and desktop

## 🏗️ Technology Stack

- **Frontend**: TypeScript
- **Styling**: TailwindCSS
- **Charts**: Chart.js
- **Storage**: IndexedDB
- **Build Tool**: Vite
- **Testing**: Vitest

## 🏥 Privacy & Security

- **Local Storage Only** - All health data stays on your device
- **No Server Required** - Static app with no backend dependencies  
- **No Tracking** - No analytics, cookies, or data collection
- **Export Control** - Full data portability via CSV/JSON export

## 🛠️ Development

### Prerequisites

- Node.js 20+
- npm

### Quick Start

```bash
# Clone the repository
git clone https://github.com/cosmicspork/personal-health-dashboard-poc.git
cd personal-health-dashboard-poc

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173
```
